# Claude 官网质感拆解（2026-11-19）

来源：claude.com 首页、claude.com/product/overview。数值来自页面的 CSS 变量和计算样式，截图在浅色（象牙白）模式下采集。
用途：CanvasAnvil 门户改版的设计依据。只学质感和手法，不搬对方的字体文件、插画纹理、照片和文案。

## 1. 一句话总结

**纸面一样的暖白底 + 衬线大标题 + 极少的颜色 + 很慢很软的动效 + 真实内容当主角。**
没有渐变光晕、没有发光、没有网格、没有玻璃。所有"高级感"来自字体、留白、节奏和动效曲线。

## 2. 颜色

全站一套暖灰阶（偏黄的灰，不是冷灰），加一个陶土橙和几只低饱和"色卡"。

| Token | 值 | 用途 |
|---|---|---|
| gray-050 | `#faf9f5` | 主背景（象牙白） |
| gray-100 | `#f5f4ed` | 次背景 |
| gray-150 | `#f0eee6` | 第三背景：分区色块（如 Roles、FAQ、结尾 CTA 整段铺这个色） |
| gray-200 / 300 | `#e8e6dc` / `#d1cfc5` | 细边框 |
| gray-500 | `#87867f` | 次要文字 |
| gray-600 / 750 | `#5e5d59` / `#30302e` | 三级 / 二级文字 |
| gray-950 | `#141413` | 正文与标题（不是纯黑） |
| gray-850 / 900 | `#1f1e1d` / `#1a1918` | 深色模式底 / 页脚 |
| clay | `#d97757`（hover `#c6613f`） | 唯一强调色：Logo、"Ask Claude" 这类品牌按钮、发送键 |
| peach | `#ebc9b7` | 插画色卡 |
| heather | `#cbcadb` | 插画色卡 |
| cactus | `#bcd1ca` | 插画色卡 |
| sky / mineral / plum | `#6a9bcc` / `#629987` / `#827dbd` | 偶尔点缀 |

要点：
- 主按钮是**墨色**（`#141413` 底白字），不是橙色。橙色只在少数品牌位出现。
- 分区靠**整段换底色**（050 → 150 → 050），不靠边框和卡片。
- 色卡颜色只用在插画、媒体衬底上，从不用在文字和按钮上。

## 3. 字体

- 三套自有字体：anthropicSerif（标题、引言、部分正文）、anthropicSans（导航、正文、按钮）、anthropicMono（编号、标签）。
- 标题**全部衬线、字重 500**（不是粗体）、字距正常。
  - display-1：约 72px / 行高 1.1（首屏）
  - headline-1：52px / 1.2（分区标题，如 "Put Claude to work"）
  - headline-6：19px / 1.2（卡片小标题，衬线 500）
- 正文 15–17px，行高约 1.5–1.6；副标题常用 19–20px、二级灰。
- 编号和标签：mono 或 sans，**大写、小号、0.05em 字距**（"01""02""03"、"8AM"、"FIG"）。
- 字体特性：`"pnum","lnum","liga"`，数字用等高。
- 标题 `text-wrap: balance`，换行均匀，不会剩一个孤字。

CanvasAnvil 对应方案：
- 英文衬线用 Source Serif 4（已在依赖里），中文衬线用思源宋体 / Noto Serif SC 500。
- 无衬线用 Inter 加系统黑体，等宽用 JetBrains Mono。

## 4. 版式与间距

- 分区上下留白很大：主分区 8rem，大分区 12.5rem，页顶 15rem。
- 内容最宽约 1194px；首屏标题限宽 704px、居中。
- 圆角体系：4 / 6 / 8 / 12 / 16 / 24 / 32。
  - 按钮 8、小 chip 6、卡片 16、媒体块 12～32（随屏宽变化）。
  - 首屏方块 tile 是 7.5%（"超椭圆"手感）。
- 阴影极轻：`0 4px 24px rgba(0,0,0,.05)`、`0 3px 10px rgba(0,0,0,.05)`。只有浮层用，平面元素不用。
- 三栏"编号 + 衬线小标题 + 灰色正文"，上方一条 1px 细线，是它的招牌信息块。

## 5. 动效：曲线与时长

CSS 变量里定义了一整套缓动，最常用的是这三条：

```
--ease-out-power2: cubic-bezier(.25, 1, .5, 1)    // 标题逐词淡入
--ease-out-expo:   cubic-bezier(.19, 1, .22, 1)   // 导航颜色 0.5s
--ov-ease-out-soft:cubic-bezier(.215,.61,.355,1)  // 卡片、浮层、面板
--ov-ease-out:     cubic-bezier(.23, 1, .32, 1)
--ov-ease-travel:  cubic-bezier(.77, 0, .175, 1)  // 大位移"旅行"
```

时长分布：小交互 0.15–0.25s；内容入场 0.45–0.65s；标题逐词 1s；色彩过渡 0.4–0.6s。
所有动效都**只动 opacity 和 transform**，位移很小（4–8px，最大 40px），偶尔配 `scale(.98 → 1)`。

## 6. 动效：具体手法（逐个可复刻）

1. **标题逐词淡入（AnimatedHeading）**
   - 每个词包一个 span，`opacity 0 → 1`，`transition: opacity 1s var(--ease-out-power2)`。
   - 延迟为 `word-index × 0.0667s`，进入视口时给标题加 `.revealed`。
   - 没有位移，只有淡入，所以非常"静"。
2. **首屏标题遮罩上滑（hmask / hword）**：外层 `clip-path: inset(0 -.1em -.15em)`，词从下方滑入。
3. **首屏方块环（OverviewHero ring）**
   - 65 个圆角方块围成一个大环，绕着标题缓慢漂移；滚动时向外散开、轻微旋转（±3°）、逐个淡出。
   - 方块分两种：一种是真实照片或视频片段，一种是空白色块叠一条手绘曲线纹理（同一个 squiggle 做 8 个方向的旋转和镜像）。
   - 环整体用 mask 渐隐，四周淡出，下沿 67% → 97% 渐隐。
   - 悬停方块会弹出说明小卡：`opacity + translateY(6px) scale(.98) → 0 / 1`，0.25s。
4. **入场上浮（tabFadeUp / artifactIn）**
   - `translateY(40px) → 0` 配淡入，0.65s，soft 曲线。
   - 同组子元素依次延迟：`0.2s + index × 0.1s`。
5. **吸顶滚动叙事（RolesBand）**
   - 整段吸顶。左边是时间刻度尺（8AM / 12PM / 4PM，15px 细横线），随滚动逐格点亮，每格延迟 85ms。
   - 中间是彩色纹理衬底，上面一个输入框在打字。衬底后面叠两张不同色的卡，露出顶边，像一叠纸。
   - 下方一排应用图标坞，当前用到的图标下面有小圆点。
   - 每一屏换一个场景，提供"修改提示词 / 重播"两个按钮。
6. **用例库（UseCaseLibrary）**
   - 一句可填空的大句子："I'm in [Marketing] and I need to make the [Campaign readout]."，填空处是下划线，可以点开选。
   - 左边角色列表、右边任务列表。未选中项 0.4 透明度，悬停时其他项降到 0.3。
   - 中间是叠放的彩色纸张，最上面一张是真实产出物（PPT 窗口）。
7. **按钮**
   - 主按钮墨色底。hover 时不变色，而是外扩一圈 2px 同色描边：`box-shadow: 0 0 0 2px`。
   - 次按钮是 1px 边，hover 变 2px。
   - 按下时 `scale(.97)`。
8. **列表悬停降噪**：`menu:has(item:hover) item:not(:hover) { opacity:.3 }`，聚焦你指着的那一项。
9. **证言（Testimonial）**：引言里的词随音频播放逐个变色（color 0.4s），配波形播放器。
10. **FAQ**：上下细线分隔，＋号展开，用 `interpolate-size: allow-keywords` 让高度能平滑过渡。
11. **结尾 CTA**：整段 gray-150 底，衬线两行大字，下面一个**输入框式按钮**（"How can I help you today?" + 陶土色 "Ask Claude ↑"），直接把产品交互搬上门户。
12. **导航**：首次进入从上往下滑入（navSlideDown，20px）。下拉面板用 `clip-path` 揭开，子项依次上浮。
13. **无障碍**：动画时长有 `0.01ms` 的规则，即尊重 `prefers-reduced-motion`。

## 7. 照片与插画

- 照片：暖色调、自然光、真实工作场景（人在书桌前、贴满纸的墙），大圆角裁切。
- 插画：
  - 单色细线，像钢笔线稿（定价页的植物图标）；
  - 或在色卡底上叠一条随意的手绘曲线（squiggle）。
  - 绝不用 3D、渐变和发光。
- 媒体块都放在"色卡底 + 叠纸"的结构里，再小也有呼吸感。

## 8. 搬到 CanvasAnvil 的对应关系

| Claude 手法 | CanvasAnvil 版本 |
|---|---|
| 首屏方块环（照片/视频 + 纹理块） | 方块里放我们真实的作品缩略图：框架图、户型图、PPT 页、白板图，再加手绘纹理块；滚动散开，悬停弹出作品名 |
| 标题逐词淡入 | 中文按词组切分（如 "把想法，" "落成" "一张图。"），同一曲线、同一时长 |
| 吸顶时间轴叙事 | 左边是步骤刻度（描述 → 生成 → 圈选 → 导出），中间色卡衬底上演示一个画布的完整过程，四个画布轮换 |
| 可填空大句子 | "我想画一张 [研究框架图]，用在 [开题报告] 里。" 点开可切换，下面换真实作品 |
| 编号三栏 | 01 结构化生成 / 02 圈哪改哪 / 03 导出可编辑（draw.io、施工图、可编辑 PPT） |
| 输入框式结尾 CTA | "想画点什么？" 输入框，点击直接进入对应画布并带上这句话 |
| 墨色主按钮 + 外扩描边 hover | 同样做法，陶土色只留给 Logo 和发送键 |

## 9. 不能照搬的东西

- anthropicSerif / Sans / Mono 是自有字体，不能用，改用 Source Serif 4、思源宋体、Inter。
- 对方的照片、squiggle 纹理、插画、文案和 Logo 都不能用，纹理要我们自己画。
- 我们的产品图要压到暖色调里：衬底统一用 gray-150 或色卡色，避免冷白截图把页面"打冷"。
