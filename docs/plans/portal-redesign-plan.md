# 门户改版方案：Claude 质感（2026-11-19）

设计依据：[claude-style-study.md](claude-style-study.md)。
范围：门户首页 + 四个画布详情页（`client/pages/portal/`）。画布内部界面不动。

---

## 0. 目标与原则

**目标**：打开门户的第一眼，像打开一本安静、讲究的作品集。看得出这是一个认真做的产品，而且 5 秒内能看懂"一句话 → 一张能用的图"。

**五条原则**（每一屏都按这五条自查）：
1. **纸面感**：象牙白底，分区靠整段换底色，不用边框盒子把内容框起来。
2. **字说话**：衬线大标题（字重 500），正文灰阶分三级，一屏只有一个视觉重点。
3. **作品是主角**：每一屏都有真实产出物（框架图、户型图、PPT 页、白板图），装饰只有手绘线条。
4. **慢而软**：只动透明度和位移，位移 ≤ 40px，曲线统一用第 2.5 节那几条，不弹跳、不发光。
5. **克制用色**：主按钮用墨色；陶土橙只给 Logo、发送键和一处关键词手绘下划线；色卡只给插画和媒体垫底。

## 1. 现状与要变的地方

| 现状 | 改为 |
|---|---|
| 深色底 + 网格背景 + 轨道图 | 象牙白底（深色模式跟随 App 主题），无网格 |
| 整页装在一个圆角大卡片里 | 全宽铺满，分区换底色 |
| **滚轮翻页**（首页 → 4 个画布页，一页一屏） | **普通长页面滚动**，配滚动触发动效（Claude 就是这么做的）。⚠ 这是交互方式的改变，需要你确认 |
| 一个 1023 行的 `PortalPage.tsx` | 拆成分节组件，见第 6 节 |
| 首屏只有一屏内容 | 首页 9 个分区 |
| 英文用无衬线，中文黑体 | 标题全部衬线：Source Serif 4 + 思源宋体 |

保留的：
- 教程入口、中英切换、GitHub 链接、`onEnterWorkspace` / `onOpenTutorials` 接口；
- `portal:navigate` 事件（改成滚动到对应锚点）；
- 详情页的文案数据（`detailConfigs`），重新排版即可。

## 2. 设计系统（只在门户内生效，挂在 `.portal` 根节点上）

### 2.1 颜色变量

```css
.portal {
  --p-bg:        #faf9f5;  /* 主底 */
  --p-bg-2:      #f5f4ed;
  --p-bg-3:      #f0eee6;  /* 分区色块 */
  --p-paper:     #ffffff;  /* 浮起的纸、卡片 */
  --p-line:      #e8e6dc;  /* 细线 */
  --p-line-2:    #d1cfc5;
  --p-ink:       #141413;  /* 标题、正文、主按钮 */
  --p-ink-2:     #3d3d3a;  /* 二级文字 */
  --p-ink-3:     #73726c;  /* 三级、说明 */
  --p-clay:      #d97757;  --p-clay-hover: #c6613f;
  --p-peach:     #ebc9b7;  --p-heather: #cbcadb;  --p-cactus: #bcd1ca;  --p-oat: #e3dacc;
}
.dark .portal {
  --p-bg: #1f1e1d; --p-bg-2: #262624; --p-bg-3: #30302e; --p-paper: #262624;
  --p-line: #3d3d3a; --p-line-2: #4d4c48;
  --p-ink: #faf9f5; --p-ink-2: #c2c0b6; --p-ink-3: #9c9a92;
  /* 色卡在深色下降低亮度：peach #8a6a5c、heather #6e6d80、cactus #5e7570 */
}
```

四个画布各认领一只色卡（用作衬底和小圆点，不用在文字上）：
- 图表 → cactus；
- 室内设计 → oat；
- PPT → peach；
- 自由画布 → heather。

### 2.2 字体

| 角色 | 英文 | 中文 | 字重 |
|---|---|---|---|
| 标题 / 引言 | Source Serif 4（已有） | 思源宋体 Noto Serif SC（新增 `@fontsource/noto-serif-sc`，按 unicode-range 分片，只有门户加载） | 500 |
| 正文 / 按钮 / 导航 | Inter（已有） | 系统黑体（PingFang SC / 微软雅黑） | 400 / 500 |
| 编号 / 标签 | JetBrains Mono 或 Inter 大写 | — | 400，字距 0.05em |

### 2.3 字号（桌面 / 手机）

| 级别 | 用途 | 桌面 | 手机 | 行高 |
|---|---|---|---|---|
| display | 首屏标题 | 72px（中文 64px） | 44px | 1.1 |
| h1 | 分区标题 | 52px（中文 46px） | 34px | 1.2 |
| h3 | 卡片标题（衬线） | 20px | 18px | 1.3 |
| lead | 副标题 | 20px | 17px | 1.55 |
| body | 正文 | 16px | 15px | 1.65 |
| micro | 编号 / 标签 | 12px 大写 | 11px | 1.4 |

中文标题比英文小一档，因为同字号下汉字视觉上更重。

### 2.4 间距、圆角、阴影

- 分区上下内边距：主分区 128px，大分区 200px，首屏顶部 160px；手机减半。
- 内容最宽 1200px，首屏标题限宽 720px，正文段落限宽 640px。
- 圆角：按钮 8，chip 6，卡片 16，媒体块 24，首屏方块 7.5%。
- 阴影只有两档：
  - `--p-shadow-1: 0 3px 10px rgba(0,0,0,.05)`
  - `--p-shadow-2: 0 4px 24px rgba(0,0,0,.05)`

### 2.5 动效

```css
--p-ease-word:   cubic-bezier(.25, 1, .5, 1);     /* 标题逐词 */
--p-ease-soft:   cubic-bezier(.215, .61, .355, 1); /* 入场、浮层 */
--p-ease-out:    cubic-bezier(.23, 1, .32, 1);     /* 菜单、卡片 */
--p-ease-travel: cubic-bezier(.77, 0, .175, 1);    /* 大位移 */
```

时长：
- 悬停、按下：0.15–0.2s；
- 浮层：0.25s；
- 内容入场：0.6s（同组依次 +0.1s）；
- 标题逐词：1s（每词 +0.067s）；
- 颜色过渡：0.4s。

开启"减少动态效果"时，全部动效直接跳到终态（App 里已有 `MotionConfig reducedMotion="user"`，CSS 侧也要补上）。

### 2.6 组件

- **主按钮**：墨色底、白字、圆角 8、高 40；hover 外扩 2px 同色描边（`box-shadow: 0 0 0 2px`），按下 `scale(.97)`。
- **次按钮**：透明底，1px `--p-line-2` 描边，hover 变 2px。
- **品牌按钮**（只用在结尾输入框里）：陶土色底、白字。
- **chip**：高 28、圆角 6、1px 细边、12px 字。
- **编号信息块**：顶部一条 1px 细线，下面依次是编号（micro）、衬线小标题、灰色正文。
- **纸叠**：主卡片之后错位叠两张色卡纸（上移 12px、左右各缩 16px），露出顶边。

## 3. 首页逐屏设计

### S0 顶栏

- **布局**：
  - 左：衬线字标 CanvasAnvil，前面是陶土色铁砧小图标；
  - 中：画布 · 作品示例 · 工作方式 · 常见问题；
  - 右：教程、中/EN、GitHub 图标、主按钮"开始创作"。
- **吸顶**：底色是 `--p-bg` 的 92% 不透明。不用毛玻璃，滚动后底部出现 1px 细线。
- **动效**：首次进入时整条从上方滑入（-20px → 0，0.6s soft）。导航项 hover 颜色在 0.5s 内从三级灰变成墨色。
- **手机**：只留字标、"开始创作"和菜单按钮。菜单面板用 `clip-path` 从上往下揭开，子项依次上浮 20px。

### S1 首屏：作品之环

**画面**
- 正中是衬线大标题（两行）、一行副标题、两个按钮。
- 四周是一圈约 40 个圆角方块，围成一个大椭圆环，整体缓慢漂移。环的上、左、右三边渐隐，下沿 67% → 97% 渐隐。
- 方块分三种：
  1. **作品块**（约 60%）：真实作品缩略图（四个画布各 6–8 张），方块下方一行小字说明，如"开题报告框架图""三室两厅平面布置""低碳校园 · 第 3 页"。
  2. **纹理块**（约 30%）：画布色卡底加一条自己画的手绘曲线，8 个方向旋转或镜像复用。
  3. **过程块**（约 10%）：小视频或 GIF 片段，比如框架图节点逐个出现、圈选后局部重绘。

**文案**
- 中文
  - 标题：把想法，落成一张图。
  - 副标题：图表、户型与施工图、演示文稿、白板。一句话起笔，一处一处地改。
- 英文
  - 标题：Where ideas take shape.
  - 副标题：Diagrams, floor plans, decks and boards. Start with a sentence, refine one stroke at a time.
- 按钮：主按钮"开始创作"，次按钮"看看能做什么 ↓"（滚动到 S3）。

**动效**
- 标题：遮罩上滑，每个词从下方 0.3em 滑入，配 1s 的 word 曲线，词间隔 0.067s；副标题和按钮随后 0.2s 淡入。
- 环：方块从中心向外"展开"到各自位置，1.2s travel 曲线，依次延迟 10ms。之后每个方块各自做极慢的漂移（周期 20–40s，幅度 4–8px，转角 ±0.5°）。
- 滚动：首屏滚出过程中，方块沿径向外推、旋转 ±3°、按距离依次淡出；标题上移并淡出。用 motion 的 `useScroll` 和 `useTransform` 实现。
- 悬停作品块：弹出一张小纸卡（宽 220px），显示作品名、所属画布色点和"打开这个画布 →"，0.25s，`translateY(6px) scale(.98)` → 原位。

**手机**：环改成首屏下方两条反向缓慢平移的方块带，左右渐隐。

### S2 一段话 + 三个编号块

- **视频卡**（可选）：居中一张 16:9 圆角卡，放一段 30–45 秒的产品录屏，中间是墨色方形播放键；没有录屏时用一张静态长图代替。
- **三栏编号块**（顶部细线）：
  - 01 **一句话就够了**：不用会画图，也不用学工具。说清楚要什么，结构、排版、配色交给它。
  - 02 **圈哪改哪**：对哪里不满意就圈哪里，只重画那一处，别的地方一笔不动。
  - 03 **拿去就能用**：draw.io 文件、施工图与报价、可编辑 PPT、PDF，交付或者接着改都行。
- **动效**：三栏依次上浮（40px → 0，0.65s，间隔 0.1s），顶部细线从左到右画出（`scaleX 0 → 1`，0.8s）。

### S3 吸顶叙事：一张书桌，四种画布（核心屏）

**结构**：底色 `--p-bg-3`，总高约 4 屏，内容吸顶。滚动推进四个场景，每个画布一个。

**左栏**
- 一条刻度尺，四个大刻度（图表 / 室内设计 / PPT / 自由画布），每个大刻度之间 6 条 15px 细刻度。
- 当前场景的刻度点亮成墨色，细刻度按 85ms 依次点亮。
- 刻度旁是场景标题和说明，切换时淡出再淡入。

**右栏**
- 画布色卡纸面，后面叠两张其他画布的色卡纸。纸面上叠一张白色"窗口"，按时间轴演示一个完整过程：
  1. 输入框里逐字打出需求，比如"画一张开题报告的研究框架图"；
  2. 窗口里依次出现 3–4 条步骤（✓ 拆出 4 个层级 / ✓ 生成节点与连线 / ✓ 自动排版）；
  3. 作品图淡入；
  4. 一个手绘圈出现在作品某处，配批注"这里换成横向"，被圈出的区域换成修改后的版本；
  5. 底部浮出导出 chip：`draw.io` `PNG` `SVG`。
- 下方两个次按钮：**换一句话**（跳到 S4）和 **重播 ↻**。
- 下方再放一排小图标坞（四个画布图标），当前画布下面有小圆点，点击可直接跳到该场景。

**四个场景的脚本**

| 画布 | 打字内容 | 步骤 | 作品图 | 圈改 | 导出 chip |
|---|---|---|---|---|---|
| 图表 | 画一张开题报告的研究框架图 | 拆层级、生成节点连线、自动排版 | diagram/01 | 圈"研究方法"一层："拆成三个并列模块" | draw.io / PNG / SVG |
| 室内 | 三室两厅，主卧带衣帽间，客厅朝南 | 整理方案、生成户型、自查 | cad/floorplan-furniture | 圈主卧："衣帽间放到门后" | 施工图 PDF / DXF / 报价单 |
| PPT | 一份 12 页的 AI 内容创作分享 | 拟大纲、定风格、逐页生成 | ppt/ppt1 首页 | 圈标题区："换成更沉稳的配色" | 可编辑 PPT / PDF |
| 白板 | 海边灯塔，黄昏 | 生成上板 | canvas/01 → 03 | 圈天空："加一群海鸥" | 版本谱系 v1 → v2 |

**手机**：取消吸顶，四个场景纵向排列，每个场景进入视口时自动播放一次。

### S4 一句填空：你想画什么？

**大句子**（衬线 h1，居中）：

> 我想画一张 <u>研究框架图</u>，用在 <u>开题报告</u> 里。
> I want a <u>research framework</u> for my <u>thesis proposal</u>.

- 两处下划线可以点开：点击后弹出圆角 24 的纸卡菜单，悬停项之外的选项降到 0.3。
- 左栏是"画布"列表，右栏是"用途"列表，未选项透明度 0.4，前面有 15px 细线标记。
- 中间是纸叠：底色跟随所选画布的色卡，最上面一张是对应的真实作品图（加白窗口外框、圆角 6、`--p-shadow-2`），右下角一个小按钮"用这句话开始 →"。
- 切换时作品图淡出，随后新图上浮 8px 淡入（0.45s soft）。

**数据**：每个画布 4–6 个用途，每个用途配一张作品图和一句话 prompt。先用现有 16 张示例图，不够的后补。
- 图表：开题报告、系统设计评审、项目汇报、课程讲义
- 室内：自住装修、出租房翻新、报价核对、施工交底
- PPT：组会汇报、路演、课程分享、述职
- 白板：海报草图、插画构思、产品概念、灵感板

### S5 特写：圈哪改哪

- 底色 `--p-bg`。左边是衬线标题"只改你圈出的那一处。"加一段说明；右边是修改前 / 修改后的对比图，中间一根可拖动的竖向分隔线，图上有一个手绘圈。
- **动效**：进入视口时，手绘圈用 `stroke-dashoffset` 在 0.9s 内画出来，随后分隔线自动从左滑到中间演示一次。用户也可以自己拖。
- **素材**：自由画布 02 → 03 现成；图表可以用 diagram 的修改前后图（需要补一对）。

### S6 我的作品

- 衬线标题"每一份，都留着。"，加说明：每个画布都能存多份作品；点保存才更新；草稿不会进列表。
- 下面是一排作品卡，像书架上斜放的画册：轻微错落和 ±1.5° 旋转，hover 时摆正并上浮 4px。
- 卡片内容：缩略图、作品名，以及"保存于 11 月 18 日"这类时间说明。

### S7 常见问题

两栏布局：左边是衬线大字"常见问题"，右边是问答列表（上下细线，＋号旋转 45° 变成 ×，高度平滑展开）。
1. 需要自己的模型 API 吗？
2. 数据存在哪里？
3. 导出的文件能在别的软件里打开吗？（draw.io / DXF / 可编辑 PPT）
4. 和 Codex / Claude Code 怎么一起用？
5. 能商用吗？（MIT）
6. 作品会自动保存吗？

### S8 结尾：想画点什么？

- 底色 `--p-bg-3`，上下各 200px 留白。
- 衬线两行大字："想画点什么？ / 写一句就好。"
- 下面是一个输入框式的长条（白底、圆角 16、1px 细边），占位文字"比如：画一张开题报告的研究框架图"，右侧陶土色按钮"开始 ↑"。
- 行为：回车或点击后，按关键词猜测画布（框架 / 流程 / 架构 → 图表；户型 / 装修 → 室内；PPT / 演示 → PPT；其他 → 白板），进入画布并把这句话填进输入框。需要给画布加一个"预填输入"的入口，见 6.3。
- 输入框下方一排四个画布 chip，可以手动指定画布。

## 5. 双语、深色、手机、无障碍、性能

- **双语**：所有文案放进 `copy.ts`，结构为 `{ zh, en }`；中文标题按词组切分（逐词动画用），英文按空格切分。
- **深色**：跟随 App 的 `.dark` 主题，用 2.1 节的深色变量；作品图外框在深色下仍保持白纸，像暗处的一张纸。
- **手机**：
  - 首屏的环改成横向方块带；
  - S3 取消吸顶；
  - S4 的左右栏变成上方两个下拉框；
  - 宽度 ≥ 360px 时无横向滚动。
- **无障碍**：
  - 动效遵循减少动态效果设置；
  - 逐词动画的标题保留 `aria-label` 存放整句，词 span 设 `aria-hidden`；
  - 所有可点元素都有 focus-visible 外框（2px 墨色）；
  - 对比度：三级文字 `#73726c` 在象牙白上约 4.6:1，达标。
- **性能**：
  - 首屏方块用 webp 缩略图（≤ 30KB/张，宽 240px），总共约 1MB 以内，其余图片懒加载；
  - 思源宋体只加载用到的分片；
  - 滚动动画只改 transform 和 opacity，加 `will-change`，环的漂移用一个 rAF 循环统一驱动；
  - 首屏滚出后暂停环的循环。
