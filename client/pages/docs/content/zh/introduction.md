# 简介

CanvasAnvil 是一张安静的工作台：你用一句话说出想要的东西，它在画布上替你起好第一稿，然后陪你一笔一笔改下去。

它把四种常做的创作放在同一个工作区里——图表、室内设计、演示文稿和自由的图片创作。每一张画布都有自己的工具，却说着同一种语言：左边是对话，右边是作品；AI 给出第一稿，你始终握着最后一笔。

## 四张画布

| 画布 | 适合做什么 | 交付什么 |
| --- | --- | --- |
| [图表绘制](/docs/diagram) | 架构图、流程图、研究框架、课程导图 | 可编辑的 draw.io 图，导出 drawio / SVG / PNG |
| [室内设计](/docs/interior) | 从一句需求或一张原始户型图开始做装修方案 | 可编辑户型、3D 漫游、报价单、施工图、DXF、彩平图 |
| [PPT 演示](/docs/ppt) | 汇报、提案、课程讲义 | PDF、图片版 PPTX、可编辑 PPTX |
| [自由绘制](/docs/canvas) | 海报、插画、在一张图上反复修改 | 图片，以及同一张图的每一个版本 |

## 它相信的几件事

**AI 做出来的，都能接着改。** 生成只是开始。图表里的每个方框、户型里的每面墙、幻灯片里的每一页，都是可以再动的对象，而不是一张定格的图片。

**模型负责判断，代码负责精确。** 模型擅长理解你要什么、懂得取舍，却不擅长算术。所以凡是需要坐标、尺寸、对齐的地方，都交给确定的代码来做。这条分工贯穿每一张画布，[设计取向](/docs/principles) 一篇专门讲它。

**你的东西留在你这里。** 作品存在浏览器自己的数据库里，模型密钥只保存在本地设置中。CanvasAnvil 不设账号，也不经手你的数据。

> [!TIP]
> 第一次来，建议按顺序读：[快速开始](/docs/quickstart) → [接入模型](/docs/models) → 任选一张画布的指南。想知道它为什么这样做，再去「原理」一组。

## 这份文档怎么读

- **开始使用**：把它跑起来，接上你的模型。
- **画布指南**：每张画布怎么用，从第一句话到导出。
- **功能**：作品如何保存，设置里每一项是什么。
- **原理**：底层的算法与策略，以及当初为什么这样选择。
- **技能与插件**：在 Claude Code、Codex 等编程助手里直接打开画布。
- **开发者**：代码怎么组织，怎么加一张新画布。

按 `Ctrl K`（Mac 上是 `⌘ K`）可以随时搜索整份文档。
