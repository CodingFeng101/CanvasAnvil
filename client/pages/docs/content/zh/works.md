# 作品与保存

屏幕上的就是保存下来的。不必记得按保存，也不必担心刷新——像在 claude.ai 里聊天一样，你做的每一点都已经留下了。

## 我的作品

顶部的「我的作品」按 全部 / 图表 / 室内设计 / PPT / 自由绘制 分类列出所有作品，可以打开、改名、复制和删除。从这里打开另一张画布的作品，会直接切换过去。

一份作品一旦有了内容，就会自己出现在列表里；什么都没画就离开的空草稿会被丢弃，不会堆成一串「未命名」。

```diagram
works
```

## 清空

清空对话会先弹窗确认（可以在 设置 → 通用 里关掉）。已经列出的作品仍留在「我的作品」里，画布换成一份新的空白作品。

## 备份与迁移

作品存在浏览器自己的 IndexedDB 里，换浏览器或换电脑不会自动带过去。可以在 设置 → 数据 里：

- **导出全部作品**：得到一个 JSON 文件，包含四张画布的所有作品，以及它们在 localStorage 里的小设置；
- **导入**：选择之前导出的文件，确认后替换当前全部作品，然后页面会重新载入。

> [!TIP]
> 清理浏览器数据之前，先导出一份备份。

背后的存储结构见 [作品如何保存](/docs/works-storage)。
