# 更新日志

每一次值得一提的变化。最新的在最上面。

## 2026-11-22

### 新增

- **作品互相引用**：PPT 可以引用图表、自由绘制的图和室内设计（做装修汇报）；自由绘制可以引用 PPT 和图表的图来标注修改。
- **用笔画出来**：图表和室内设计生成时，一支铅笔先把轮廓描出来；生成图片时轮流播三段钢笔速写。
- **图表自己选排版**：给出每种排版的分数，由你挑一种点「确定」，之后都在这张图上改。「读取文件」一步能展开看到每个文件的摘要和原文。
- **PPT 先问再做**：只传 PDF、不写字时，先问是做新 PPT 还是逐页美化。导出的 PPTX 带上演讲备注。
- **并发数可调**：设置 → 画布里可以改 PPT 同时生成几页、读长文件时同时摘要几段。
- **桌面版下载**：设置 → 关于和首页顶栏都有下载 Windows 桌面版的入口。
- **本地 draw.io**：安装时下载一份 draw.io，图表画布不依赖外网。

### 修复

- 室内设计的自动修复只盯错误：挪不开就稍微缩小，警告可以接受；生成时家具一件一件出现；去掉了对话框上方的检查清单。
- 图表发出的文件恢复成统一的附件样式，复制按钮只复制你写的字，文件不再读两次。
- 设置里重复的「搜索作品」快捷键不会再出现在其他分区。
- 去掉了 CI 和没有用到的文件。

## 2026-11-20

### 新增

- **新的首页和每个画布的详情页**：长页面，安静、温暖的文艺风格，放的是各画布的真实截图和对应的提示词。在首页写下的话，点「开始创作」会带进画布。
- **工作区改成 Claude 的样子**：左侧栏有新建作品、搜索（`Ctrl + K`）、我的作品、四个画布和最近作品（可置顶、改名、删除）。新作品打开是一句问候和三张例子卡片，每张都是这个画布真实跑过的需求和它的结果，点一下就发出去。
- **自动保存**：作品边做边存，不再有「保存」按钮。「新建作品」开一份新的，旧的留在「我的作品」里，所以清空对话按钮和它的设置都去掉了。
- **内置文档**（`#/docs`）：中英文各 22 页，包括快速开始、各画布、我的作品、设置、技能、开发和常见问题、更新日志，还有一组「原理」，讲算法和为什么这样选（图表布局矫正、生成—检查—修改循环、户型排布引擎、PPT 流水线、画布修改、作品怎么存）。带搜索、本页目录和代码复制按钮。
- **设置里新增**：
  - **使用统计**：年度热力图，按天、月、小时、星期的图表，生成耗时、模型、图片、作品和 token。token 用的是服务商返回的真实用量，每轮显示，按画布累计。
  - **技能与插件**：本机一键安装、`npx` 和 `git` 命令、zip 下载。
  - **其他**：更多完成提示音、各画布占用的存储，以及记忆（全局规则）、视频、文档和关于页。
- **Claude Code 插件**：在 Codex 的清单旁边加了 `.claude-plugin` 清单，canvas 技能在 Claude Code 里也能装。

### 改进

- 第一次打开时界面语言跟随浏览器，切换只在设置里。
- 空状态、侧边栏和关于页的文字更安静，合适的地方加了手绘小图案。中文不再用浏览器硬掰出来的假斜体。
- 深度思考把读文件、参考图和草图显示为步骤；室内设计的 2D 平面跟随深色模式；PPT 画布加了页面缩略栏和放映。

### 修复

- PPT：开始页重新显示把输入读成了什么（一句主题 / 一份提纲 / 旧文件换风格）和选中的风格，读错了可以一键切换。
- 窗口较窄时，点输入框下面的「未配置模型」也能打开设置 → 模型。
- 首页点「开始创作」时，下面的图片还在加载也不会再滚过头到页脚。
- 文档里同名的标题（更新日志每个日期下的「新增」）各有自己的锚点。

### 说明

- 去掉了：旧的教程页（视频改在设置 → 视频里）、保存按钮和保存对话框、清空对话按钮和「清空对话前确认」。

## 2026-11-18

### 新增

- **我的作品**：每张画布都能存多份作品。顶部「我的作品」按画布分类列出所有作品，可以打开、改名、复制、删除；从这里打开另一张画布的作品会直接切过去。
- 升级前已有的内容会自动成为第一件作品，原来的数据保留不动。

### 改进

- **图表画布改存到 IndexedDB**：长对话不会再因为 localStorage 容量满了而保存失败；旧数据第一次打开时自动搬过去；生成过程中每 3 秒保存一次。
- **draw.io 加载不出来时自动换备用地址**：默认地址 8 秒内没加载好，会改用 GitHub Pages 上的镜像；两个都不行时显示提示和「重试」。
- **安装插件不用再克隆仓库**：直接从 GitHub 添加插件市场。市场名改为 `canvasanvil`，之前按 `canvasanvil-local` 添加过的需要重新添加一次。

## 2026-11-13

### 修复

- **图表绘制**：图已经画好，「绘制图表」却一直转圈；局部修改报错。原因是依赖升级后消息格式变了，旧格式的工具结果写不回去。现在打开旧会话时会自动补齐格式。
- **室内设计**：待定事项选了却像没生效。现在你的选择单独作为「用户已定事项」交给模型，与方案冲突时以你的选择为准。
- **室内设计**：生成户型时偶尔出现 `Designer unavailable`。每一步都改为使用当前的设计器。
- **室内设计**：切换画布或刷新后，生成步骤一直转圈。现在回来时显示「已中断」，并给出「重新生成户型」按钮。

### 改进

- 室内设计画布与其他画布一样占满左侧区域。
- 报价单、施工图、DXF、彩平图和效果图统一从设计器右上角导出。
