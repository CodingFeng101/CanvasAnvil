# 按标注改图

在一张图上圈一下，只改那一处。听起来简单，背后是三次转换：从笔画到几何，从几何到一句话，再从一句话到一张新图。

```diagram
canvas-edit
```

## 第一步：按几何收集标注

你选中一张图，在它上面或旁边画了几笔。`annotated-edit.ts` 先确定这些笔画属于哪张图：凡是落在图片附近搜索范围内的箭头、圈、文字，都归到这张图名下。

然后把图片和标注**按图片自己的分辨率**合成一张参考图；如果标注伸出了图片边界，就把画框放宽，让每一笔都完整可见。

> [!WHY]
> 为什么是原图分辨率？画布上的缩放只是显示。若按屏幕尺寸截图，一张 2048 像素的图可能只剩几百像素，模型看到的细节就丢了，改出来的图也会变糊。

## 第二步：把标注读成一句话

合成图交给视觉模型，让它把「这里画了什么、想改成什么」写成一句明确的修改指令。这句话会以「AI 理解的修改：……」显示在对话里。

> [!WHY]
> 图片编辑模型擅长「照着一句话改」，却不擅长解读涂鸦。先让视觉模型翻译一次，各自做擅长的事。更重要的是：如果改错了，你能看到它读出的那句话，立刻知道是「理解错了」还是「画错了」。

## 第三步：图片编辑

原图作为主参考，配上那句指令，调用生图通道的编辑接口（服务商不支持时退回对话接口）。新图放在原图旁边。

## 版本谱系

每张图在自定义数据里带一个**谱系 id**（`lineage.ts`）。从同一张原图改出来的每一版共享这个 id，版本条据此把它们串在一起。

> [!WHY]
> 版本之间从不覆盖。改图的结果难以预料，「上一版其实更好」是常事；只要每一版都还在，就永远可以回头。
