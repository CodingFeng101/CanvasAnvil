# 常见问题

几个最常被问起的问题。没有找到答案的话，欢迎到 GitHub 上提一个 issue。

## 需要自己的模型 API 吗？

需要。在 设置 → 模型 里填入你自己的模型服务地址和密钥，任何 OpenAI 兼容接口都可以。CanvasAnvil 本身不收费，也不经手你的密钥。见 [接入模型](/docs/models)。

## 我的数据存在哪里？

作品和对话都存在你自己电脑的浏览器里（IndexedDB），不会上传到 CanvasAnvil 的服务器。清理浏览器数据之前，记得先在 设置 → 数据 里导出一份。

## 作品会自动保存吗？

会。屏幕上的就是保存下来的：每次改动都写进浏览器，刷新不会丢；一份作品有了内容，就会出现在「我的作品」里，不用按保存。见 [作品与保存](/docs/works)。

## 导出的文件能在别的软件里打开吗？

能。图表导出 `.drawio` 文件，可以在任何 draw.io 里继续编辑；室内设计导出 DXF 图纸、施工图 PDF 和报价单；PPT 可以导出可编辑的 `.pptx`，每个字都能改。

## 和 Claude Code、Codex 怎么一起用？

CanvasAnvil 也是一个插件。两行命令添加插件市场并安装，就能在对话里直接打开各个画布。见 [在编程助手里用画布](/docs/skills)。

## 为什么改图时我圈的地方没改对？

先看对话里那句「AI 理解的修改：……」。如果那句话就不对，说明标注被误解了：圈得更紧一些，或者在旁边写上几个字。如果那句话是对的、图却没改对，可以换一个生图模型再试。见 [按标注改图](/docs/canvas-edit)。

## 图表排版后，我更喜欢模型原来的样子怎么办？

对话里的「布局矫正」一步可以在「矫正后」和「模型原图」之间切换。切回原图之后，后台的重排也不会再覆盖它。

## 上传户型图的按钮怎么没有？

识别户型图需要服务器上有 Python 和对应依赖（`pip install -r server/recognizer/requirements.txt`）。缺少时按钮不会显示。Docker 镜像已经自带。

## 可以商用吗？

可以。项目使用 MIT 协议开源，个人和商业用途都可以，保留版权声明即可。
