# 接入模型

CanvasAnvil 不自带模型，也不替你选厂商。它只说一种语言——OpenAI 的 HTTP 协议——而几乎所有模型服务都听得懂。

## 两条通道

设置 → 模型里有两组配置，彼此独立：

| 通道 | 用在哪里 | 需要填 |
| --- | --- | --- |
| 文本 | 对话、写图表 XML、户型布局、PPT 大纲与页面 | Base URL、API Key、模型 |
| 生图 | 自由绘制出图与改图、PPT 的图片页 | Base URL、API Key、模型 |

只做图表和户型的话，填文本通道就够了。

> [!WHY]
> 文字和图片常常来自不同的厂商：一个文本模型写得最好，另一个图片模型画得最好。把两条通道分开，就不必为了其中一个而将就另一个。

## 填写

- **Base URL**：任何 OpenAI 兼容端点，例如 `https://api.openai.com/v1`。换厂商只需要换这一行。
- **API Key**：只保存在这台设备的浏览器里，请求时随请求一起发给你填写的地址，不会经过其他地方。
- **模型**：可以加好几个，之后在输入框下方随时切换。

填好后点「测试连接」，它会发一个真实的小请求，确认能连通。

## 生图的两条路

生图请求会先试 `/images/generations`（或带参考图时的 `/images/edits`），如果你的服务不提供这个接口，再退回到用对话接口生成图片。所以无论服务商用哪种方式出图，通常都能接上。

## 用量

每次请求的 token 数和生成的图片张数都会记在 设置 → 使用统计 里，按画布、按模型、按时间分开看。这些统计只存在本地。
