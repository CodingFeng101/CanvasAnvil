# 设置一览

设置里的每一项都真的在某处起作用。这里按分组说明它们各自管什么。打开设置：点左下角，或按 `Ctrl ,`。

## 通用

| 设置 | 作用 |
| --- | --- |
| 发送键 | `Enter` 发送、`Shift Enter` 换行，或反过来用 `Ctrl Enter` 发送 |
| 启动时打开 | 上次的位置、首页，或直接进入画布 |
| 回复语言 | 跟随你的输入，或固定中文 / 英文 |

## 外观

主题（浅色 / 深色 / 跟随系统）、字号、界面密度、对话宽度、AI 回复用衬线还是无衬线字体、纸张纹理、减少动效、是否展开思考过程、是否显示 token 数。

## 画布

是否在生成后自动打开画布、画布占多大比例、是否显示小地图。

## 通知

任务完成时的系统通知与提示音，可以选音色和音量。适合生成一套 PPT 或一套户型时切到别处等它。

## 模型

文本与生图两条通道，见 [接入模型](/docs/models)。

## 记忆

写下希望 AI 一直记住的事，每次请求都会带上。有一份对所有画布生效，另外每张画布各一份：

- **全部画布**：语言、语气、品牌色；
- **图表绘制**：配色、字体、连线风格；
- **室内设计**：层高、规范、常用材料；
- **PPT 演示**：页数、版式、配色；
- **自由画布**：画风、构图偏好。

每一份都可以单独开关，不用删掉内容。

## 快捷键

| 操作 | 按键 |
| --- | --- |
| 搜索作品 | `Ctrl K` |
| 打开设置 | `Ctrl ,` |
| 放大 / 还原画布（图表） | `Ctrl B` |
| 添加图片或文件 | `Ctrl U` |
| 填入输入框里的灰色建议 | `Tab` |
| 关闭弹窗 | `Esc` |

Mac 上把 `Ctrl` 换成 `⌘`。

## 使用统计

请求次数、token、生成图片、各画布与各模型的占比，以及按周、月、年切换的趋势图。全部在本地统计，可以一键清空（会先确认）。

## 技能与插件

在编程助手里使用画布的安装方式，见 [在编程助手里用画布](/docs/skills)。

## 数据

导出、导入全部作品，清空全部作品，恢复默认设置。所有会丢失数据的操作都会先弹窗确认。

## 视频

宣传片、上手教程、版本更新、最佳实践四类，一次看一类。点一下视频，它会在右下角的小窗里播放，关掉设置也能继续看。
