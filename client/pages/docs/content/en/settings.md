# Settings

Every setting really does something somewhere. Here is what each group looks after. To open Settings, click the bottom left or press `Ctrl ,`.

## General

| Setting | What it does |
| --- | --- |
| Send key | `Enter` sends and `Shift Enter` starts a new line, or the other way round with `Ctrl Enter` to send |
| Open on start | Where you left off, the home page, or straight into a canvas |
| Reply language | Follow your input, or always Chinese / English |

## Appearance

Theme (light / dark / system), text size, density, conversation width, serif or sans for AI replies, paper texture, reduced motion, whether thinking is expanded, whether token counts show.

## Canvas

Whether the canvas opens after generating, how much room it takes, whether the minimap shows.

## Notifications

A system notification and a chime when a task finishes, with a choice of sound and volume. Handy for wandering off while a deck or a floor plan is generated.

## Models

The text and image channels; see [Connecting a model](/docs/models).

## Memory

Write down what the AI should always remember, and it goes with every request. One note applies to all canvases, and each canvas has its own:

- **All canvases**: language, tone, brand colours;
- **Diagram**: colours, fonts, line style;
- **Interior design**: ceiling height, codes, usual materials;
- **Slides**: length, layout, colours;
- **Free drawing**: style, composition.

Each one can be switched off on its own without deleting the text.

## Shortcuts

| Action | Keys |
| --- | --- |
| Search works | `Ctrl K` |
| Open settings | `Ctrl ,` |
| Enlarge / restore the canvas (Diagram) | `Ctrl B` |
| Add files or photos | `Ctrl U` |
| Take the grey suggestion in the input | `Tab` |
| Close a dialog | `Esc` |

On a Mac, use `⌘` in place of `Ctrl`.

## Usage

Requests, tokens, images generated, the share of each canvas and each model, and a trend that switches between week, month and year. All counted locally, and clearable in one go (it asks first).

## Skills and plugins

How to install the canvases into coding agents; see [Canvases in coding agents](/docs/skills).

## Data

Export and import all works, clear all works, restore the default settings. Everything that would lose data asks first.

## Videos

Four kinds (overview, tutorials, what's new, best practices), shown one kind at a time. Click a video and it plays in a small window at the bottom right, and keeps playing after Settings closes.
