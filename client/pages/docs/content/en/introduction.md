# Introduction

CanvasAnvil is a quiet workbench: say in a sentence what you want, and it lays down a first draft on the canvas, then stays with you through every revision after.

It brings four kinds of everyday making into one workspace: diagrams, interior design, slide decks and free-form pictures. Each canvas has its own tools, yet they all speak the same language: the conversation on the left, the work on the right. The AI makes the first draft; the last stroke is always yours.

## Four canvases

| Canvas | Good for | Delivers |
| --- | --- | --- |
| [Diagram](/docs/diagram) | Architecture, flowcharts, research frameworks, course maps | Editable draw.io diagrams, exported as drawio / SVG / PNG |
| [Interior design](/docs/interior) | A renovation plan from one sentence or an existing floor plan | Editable plan, 3D walkthrough, quote, drawing set, DXF, colour plan |
| [Slides](/docs/ppt) | Reports, proposals, lecture decks | PDF, image PPTX, editable PPTX |
| [Free canvas](/docs/canvas) | Posters, illustrations, reworking one picture again and again | Images, and every version of the same image |

## What it believes

**Whatever the AI makes, you can keep editing.** Generation is only the start. Every box in a diagram, every wall in a plan, every slide in a deck is an object you can still move, not a frozen picture.

**The model judges; code is exact.** A model is good at understanding what you want and at weighing choices, but poor at arithmetic. So wherever coordinates, sizes or alignment are needed, deterministic code does the work. This division runs through every canvas; [Design stance](/docs/principles) is about it.

**Your things stay with you.** Works live in your browser's own database and your model key stays in local settings. CanvasAnvil has no accounts and never handles your data.
